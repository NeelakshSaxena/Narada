feat: implement Phase 9 Skills System

This commit fulfills Phase 9 of the Narada blueprint by introducing reusable procedural knowledge (Skills) to prevent workflow hallucination.

Key additions:
- Created the core `Skill` and `SkillRegistry` abstractions in `core/skills/base.py`, enforcing a strict schema for defining inputs, outputs, constraints, verification steps, and failure behaviors.
- Codified the web research pipeline built in Phase 8 into a standalone skill definition at `skills/web_research/skill.json`.
- Integrated `SkillRegistry` into the `Executor` (`core/agent/executor.py`) by exposing `load_skill()`. This allows the agent loop to explicitly request and load the predefined constraints of a skill directly into its context, acting as a guardrail against free-form hallucination.
- Implemented serialization and integration tests in `tests/skills/test_skills.py` to mathematically prove the skill pipeline loads constraints accurately.
- Drafted the Phase 9 logbook and updated project status tracking.
