feat: implement Phase 10 Scheduled Responsibilities

This commit addresses Phase 10 of the Narada blueprint, giving the runtime the ability to execute long-running background tasks autonomously.

Key additions:
- Engineered the `Responsibility` abstraction in `core/responsibilities/models.py`, encapsulating goal, schedule intervals, persistent memory states, and bounds.
- Developed an in-process, lightweight `ResponsibilityScheduler` (`core/responsibilities/scheduler.py`) strictly avoiding the premature complexity of distributed task queues or separate docker containers.
- Implemented the "Self-Contained Prompt" engine for autonomous executions. The system spins up an entirely isolated `Executor` state for every scheduled run and dynamically builds a prompt including the goal, previous memory state, and required procedural skills without relying on conversational UI contexts.
- Added comprehensive unit tests in `tests/responsibilities/test_scheduler.py` proving time-bound scheduling and accurate prompt construction.
- Finalized Phase 10 logbook and updated tracking documents.
