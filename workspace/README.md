# Nārada Workspace

This directory is the dedicated operational workspace for Nārada.
All filesystem read and write actions are strictly confined to this folder.

## Folder Structure

- `documents/` — Notes, text files, markdown documents, drafts, and reading materials.
- `code/` — Scripts, automation code, snippets, and project files.
- `data/` — Datasets, JSON, CSV files, and structured inputs.
- `outputs/` — Generated deliverables, analysis reports, and final exports.
- `temp/` — Temporary scratch files, staging, and transient drafts.
