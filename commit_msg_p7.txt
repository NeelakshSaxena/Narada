feat: implement Phase 7 MCP tool integration and authorization gate

This commit satisfies Phase 7 of the Narada blueprint by successfully integrating the Model Context Protocol (MCP) while maintaining the absolute authority of Narada's Permission Engine over all external capabilities.

Key additions and enforcements:
- Developed the `MCPClient` and `MockMCPServer` in `core/mcp/client.py` to facilitate tool discovery and payload execution without prematurely ballooning dependencies.
- Architected the `MCPToolAdapter` (`core/mcp/adapter.py`) which intercepts external MCP tools, maps their metadata to Narada's native `ToolProvider` interface, and routes them directly into the native `ToolRegistry`.
- Upgraded the `PermissionEngine` (`core/permissions/engine.py`) to actively strip namespace prefixes (e.g., `mcp.`) so external tools are evaluated against Narada's exact internal baseline risk policies.
- Authored rigid unit tests (`tests/mcp/test_mcp.py`) proving that an external MCP tool attempting a high-risk operation (`mcp.shell.execute`) is successfully paused (`PENDING_APPROVAL`) by the local runtime, ensuring the MCP server never acts as an authorization bypass.
- Logged changes in the Phase 7 logbook and updated project status.
