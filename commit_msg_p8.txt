feat: implement Phase 8 web researcher pipeline

This commit resolves Phase 8 of the Narada blueprint by integrating native web tools and an orchestrated research pipeline.

Key additions:
- Created `WebSearchTool` and `WebOpenTool` in `providers/tools/web.py` to facilitate local web searches and content extraction without introducing heavy framework bloat.
- Registered tools in the Permission Engine as `LOW` risk.
- Developed the `WebResearcher` orchestrator in `core/agent/researcher.py`. This orchestrator strictly follows the blueprint's "Agentic research prompt" constraints: it independently breaks down queries, executes searches, tracks visited URLs to explicitly prevent infinite loops, extracts facts, and synthesizes a final memory payload.
- Added deterministic testing suite via `tests/agent/test_researcher.py` using a mock LLM state machine to prove out the pipeline flow.
- Added phase logbook and updated project status.
